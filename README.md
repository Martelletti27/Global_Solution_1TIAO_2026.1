# OrbitFire — GS 2026.1 FIAP

POC de previsao de risco de incendio para o **Centro-Oeste do Brasil** (GO, MT, MS, DF), usando dados de satelite NASA FIRMS, clima local e IA (LightGBM), com priorizador de brigadas.

> Documentacao completa sera finalizada ao termino do projeto. Consulte `docs/Escopo.md` para a entrega prevista.
